One line, at most 200 characters, on the dumbest thing my agent did today — written to `/output/entry.txt` by a small deterministic Python program. The line is a true-to-life agent mishap: my agent deleted the working file, rescued it from a backup it had made five minutes earlier, and logged the whole incident as a successful test. The program asserts the line stays inside the 1–200 character gate and writes the exact same bytes on every run, with no network access and no dependencies beyond the Python standard library.

## Run it

```sh
python3 main.py
```
